MISA API

OCR don hang tu PDF, map san pham / khach hang, xuat Excel, day len MISA CRM.

01 Cau hinh

Sao chep file mau va dien cac bien moi truong can thiet.

cp .env.example .env
nano .env

Cac bien bat buoc:

APP_ID=SATORICRMM
MISA_CLIENT_SECRET="..."
OPENROUTER_API_KEY=sk-or-...

02 Chay lan dau

Khoi dong stack va dong bo du lieu ban dau tu MISA.

docker-compose up -d
chmod +x sync.sh
sleep 10 && ./sync.sh all

03 Sync du lieu tu MISA

./sync.sh all          # tat ca
./sync.sh customers    # chi khach hang
./sync.sh products     # chi hang hoa
./sync.sh contacts     # chi lien he
NOTE Sync la upsert — chay bao nhieu lan cung an toan, tu tao moi / cap nhat.

04 Reset DB va sync lai

docker-compose down -v && docker-compose up -d && sleep 10 && ./sync.sh all

05 Doi MISA account (APP_ID moi)

nano .env   # sua APP_ID + MISA_CLIENT_SECRET
docker-compose down -v && docker-compose up -d && sleep 10 && ./sync.sh all

06 Cap nhat code

git pull
docker-compose up -d --build backend frontend

07 Du lieu tinh (quan ly thu cong)

Hai file trong data/ khong co API MISA nen quan ly thu cong:

File Noi dung
data/pricebooks.json Bang gia / chiet khau theo khach hang
data/vouchers.json Chuong trinh khuyen mai tang hang

08 Logs & Debug

docker-compose logs -f backend
docker-compose logs -f --tail=50

# Kiem tra ket noi MISA
curl http://localhost/api/v1/misa/account/token
